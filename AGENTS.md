## Sobre o projeto

Implementação do [TabNews](https://www.tabnews.com.br) feita com agentes de IA, para aplicar os conceitos das aulas do [curso.dev](https://curso.dev).

## Ambiente

Use a versão do Node definida no `.nvmrc`: rode `nvm use` antes de qualquer comando do projeto.

## Comandos

Os comandos disponíveis estão nos `scripts` do `package.json`:

```bash
npm install
npm run dev     # servidor de desenvolvimento
npm run build   # build de produção
npm run start   # serve o build de produção
```

## Arquitetura

Aplicação Next.js com App Router, escrita em JavaScript. As rotas ficam em `app/`.

## Convenções

- Código e textos da interface em português, incluindo nomes de variáveis e funções.
- Site em `pt-BR`.
